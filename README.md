# <img src="assets/icon.svg" alt="" width="48" valign="middle"> Sleep Timer for IINA

Pauses playback after 15, 30, 45, 60, or 90 minutes, or after a number of minutes you type, so you can fall asleep to a film without it playing all night.

## Install

In IINA, open Settings → Plugins, choose "Get Plugins…", enter `florinungur/iina-sleep-timer`, and choose Install.

## Use

Choose Plugin → Sleep Timer → Pause after, then a number of minutes, or choose "Custom…" and type one. When the time is up, IINA pauses the video in that window. Your Mac then sleeps on its usual schedule, unless another IINA window is still playing.

A checkmark marks the running timer. Choosing another one replaces it, and Plugin → Sleep Timer → Cancel timer stops it. The timer counts clock time, so pausing by hand doesn't stop it. Each window has its own timer, and the menu shows the one for the window in front. Closing the window or quitting IINA cancels it.
